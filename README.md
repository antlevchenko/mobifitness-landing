# Mobifitness Landing

## [EN]

A landing page for signing up for professional newsletters from Mobifitness, a service for owners of fitness studios and clubs.

**Demo**: https://mobifitness-landing.netlify.app/

### Stack

* HTML5
* Tailwind CSS v4 (CLI)

### Project Structure

```
├── icons/
├── img/
├── .gitignore
├── index.html
├── styles.css
├── package.json
└── package-lock.json
```

### Run

```
git clone https://github.com/antlevchenko/mobifitness-landing.git
cd mobifitness-landing
npm install
npm run tailwind-watch
```
Then run index.html in your browser.
